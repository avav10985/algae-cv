## 物理背景補充(評審 / 老師可能問)

**Fabry-Perot 透射公式**(Airy function):
```
T(δ) = 1 / (1 + F · sin²(δ/2))
```
- 相位差 `δ = 4π·nf·d/λ`(正向入射)
- 共振條件:`δ = 2π·m` ↔ `2·nf·d = m·λ` → 透射峰(T = 1)
- F 越大,峰越尖銳(解析能力越好)

**解析能力**:
```
R_λ = m · 𝓕
最小可分辨波長 Δλ_min = λ / R_λ
```
其中 `𝓕 = π·√F / 2` 是 finesse(峰的銳度)。

## 🔭 Step 0:Fabry-Perot 在幹嘛?

兩面鏡子面對面,距離 d:

```
 鏡子 A           鏡子 B
    │ ←── d ──→ │
    │            │
光 →│ ▶━━━━━━━▶│→ 一部分穿透
    │ ◀━━━━━━━│
    │ ▶━━━━━━━│
    │ ◀━━━━━━━│   光在裡面不斷反射
```

**問題**:光透過去的量(透射率 T)會隨 d 變化。**什麼 d 時 T 最大?**

---

## 🌊 Step 1:為什麼會有「峰值」?

光在鏡子裡來回反射,**走 1 個來回 = 2d**(過去 + 回來)。

如果 **2d 剛好等於整數個波長**(2d = m·λ),那:
- 每次反射回來的光都跟原本的光**對齊重疊**(波峰對波峰)
- → **建設性干涉** → T = 1(全透)

反之,2d 跟波長對不上 → 互相抵消 → T 很小。

```
情況 A:2d = 1λ                   情況 B:2d = 1.5λ
原波 ╱╲╱╲╱╲╱                    原波 ╱╲╱╲╱╲╱
反波 ╱╲╱╲╱╲╱  ← 對齊!          反波 ╲╱╲╱╲╱╲  ← 反相!
合成 ╱╲╱╲╱╲╱  大!               合成 ───────── 抵銷!
T = 1                              T ≈ 0
```

---

## 📐 Step 2:條件 2d = m·λ 怎麼變成 d_peak = m·λ/2?

直接除以 2:
```
2d = m·λ
 d = m·λ / 2
```

m 是「**第幾個峰**」(整數,可以是 1, 2, 3, ..., 大數)。

對 λ = 550 nm:
```
λ / 2 = 275 nm  ← 「兩個相鄰峰」的腔長差
```

也就是說,**每把鏡子拉開 275 nm,就會經過一個峰**。

---

## 🔢 Step 3:在 d = 5 cm 附近,m 是多少?

50,000,000 = m × 275
        m = 50,000,000 / 275
          = 181,818.18
```

注意 m 是**非整數**(181,818.18)。意思是 d = 5 cm 剛好**不在峰上**,離 m=181,818 的峰差了一點點。

那 m=181,818 的峰真正在哪?

                = 49,999,950 nm
                = 49,999.950 μm
                = 49.99995 mm
                ≈ 5 cm 但少 50 nm
```

跟 d_center = 50,000.000 μm 比:**差 −0.050 μm**(就是少 50 nm)。

啊好問題!**T(δ) 是「整條曲線」的公式,我用它來畫出所有峰的形狀**,不只是峰頂位置。

---

## T 是什麼?

**T = Transmission(透射率)**,是 0 到 1 之間的數字。

- T = 1 → 100% 的光透過去
- T = 0 → 完全不透
- T = 0.5 → 50% 透

它**隨著 d 變化**:你慢慢拉鏡子,T 一直在變。

---

## 我之前算的只是「峰頂」,T 公式給你「整條曲線」

| 我給你的 | T 公式告訴你 |
|---------|--------------|
| 4 個峰**在哪裡**(Δd = −0.325 / −0.050 / +0.225 / +0.500 μm)| 每個 d 的 T 值是多少 |
| 峰頂 T = 1 | 峰跟峰之間 T = 0.016(差不多 1.6%)|
| 峰的「位置」 | 峰的「**形狀**」(尖還是寬)|

**只有峰位置畫不出曲線**:

```
只用峰位置                    用 T(δ) 公式
T                             T
1 ┤  •     •     •     •     1 ┤  ▲     ▲     ▲     ▲
  │                            │  │[算式] ╱ │
  │                            │  │  ╳  │  ╳  │  ╳  │
0 ┴──────────────────→ Δd    0 ┴──┘  └──┘  └──┘  └──→ Δd
   只知道 4 個點                 完整曲線(連峰多尖、谷多深都有)
```

---

## T(δ) 公式運作的直覺

```
              1
T(δ) = ──────────────────
        1 + F·sin²(δ/2)
```

`F = 60.86` 是常數。所有變化都來自 `sin²(δ/2)`:

| sin²(δ/2) | T 的值 | 物理 |
|----------|-------:|------|
| 0(δ = 2π·m,整數)| 1 / (1+0) = **1** | **峰頂!**(光全透)|
| 0.001(剛離開峰)| 1/(1+0.061) ≈ 0.94 | 峰附近(略低)|
| 0.01 | 1/(1+0.61) ≈ 0.62 | 峰邊緣 |
| 0.1 | 1/(1+6.09) ≈ 0.14 | 峰外側 |
| 1(δ = π,最遠離峰)| 1/(1+60.86) ≈ **0.016** | **谷底**(幾乎不透)|

所以 sin²(δ/2) 從 0 → 1 反覆變化,T 就從 1 → 0.016 反覆變化,**就是那條起伏曲線**。

---

## δ 怎麼隨 d 變?

```
δ = 4π·nf·d / λ
```

d 變大一點 → δ 變大一點 → sin²(δ/2) 跟著變 → T 跟著變。

對 nf=1, λ=550nm,**d 每變 275 nm,δ 就剛好變 2π**(剛好走完一個 sin 週期 → 經過一個峰)。這就是 `λ/2 = 275 nm` 的物理意義。

---

## Python 程式怎麼用這公式畫圖

```python
def transmission(d, λ):
    δ = 4 * np.pi * nf * d / λ        # 把 d 換成相位 δ
    return 1.0 / (1.0 + F * np.sin(δ / 2) ** 2)   # 直接套公式

# 掃描 d:從 -0.5μm 到 +0.5μm,取 20000 個點
dd = np.linspace(-0.5e-6, 0.5e-6, 20000)
d = 5e-2 + dd                          # 中心 + 偏移
T = transmission(d, 550e-9)            # 每個 d 算一個 T

plt.plot(dd, T)                        # 連起來就是那條曲線
```

→ 出圖如 `fp_task2_monochromatic.png`
