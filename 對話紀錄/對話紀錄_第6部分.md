兩個都是**線性迴歸(Linear Regression)**,差別只在用幾個輸入變數。

## 共同點 — 「最小平方法」找最佳直線

給定一堆點 `(輸入, 真實 cells/mL)`,找一組係數讓:

```
總誤差² = Σ (真實 − 預測)²
```

**最小**。這叫「最小平方法(Least Squares)」,是 18 世紀就有的標準統計方法,Excel 的趨勢線、Python `numpy.linalg.lstsq()` 都用同一套數學。

## A:單變數線性迴歸(只用 R)

```
cells/mL = a · R + b
```

把 6 個點 `(R_平均, cells/mL)` 畫成散布圖:

```
cells/mL
 ↑
 │   ●  ←10 (R=0.22, 858k)
 │
 │       ●  ← 8 (R=0.33, 676k)
 │       ●  ← 9 (R=0.36, 575k)
 │            ●  ← 5 (R=0.50, 478k)
 │                  ●  ← 3 (R=0.65, 228k)
 │                       ●  ← 1 (R=0.75, 64k)
 │
 └───────────────────────────────→ R 色比
```

找一條**直線**(`y = ax + b`)最逼近這 6 個點 → 解出 `a = -1,441,330`,`b = 1,157,536`。

**幾何意義**:斜率 `a` 為負,因為 R 越小(吸光越強)→ 細胞越多。

---

## B:多變數線性迴歸(R + G + B)

```
cells/mL = a · R + b · G + c · B + d
```

把每個點當成 4 維空間裡的座標 `(R, G, B, cells/mL)`。

找一個**超平面**(類似立體的 3D 斜面)最逼近這 6 個點 → 解出 4 個係數。

**為什麼 B 精度高一點點**:多了 G、B 的資訊,可以幫忙修正只看 R 看不到的小差異(例如某張照片偏綠/偏藍時)。

**為什麼 B 係數正負夾雜**:R/G/B 互相高度相關(同進同退),迴歸找最佳擬合時,**個別係數會在「相互抵消」的方向上跑**,失去物理意義。

---

## 數學上一模一樣,只是維度不同

| | 輸入維度 | 解的維度 | 幾何 |
|--|--------|--------|------|
| A | 1(只有 R)| 2(a, b)| 一條直線 |
| B | 3(R, G, B)| 4(a, b, c, d)| 一個 3D 斜超平面 |

兩個都用 **`numpy.linalg.lstsq()`** 一行解完(內部是 SVD 矩陣分解)。

---

## 為什麼 R² 不同

```
R² = 1 − 殘差² / 總變異²
```

- A:R² = 0.9862(R 一個變數已經解釋 98.6% 變異)
- B:R² = 0.9919(再加 G、B 多解釋 0.6%)

多 0.6% 是 G、B 提供的「殘餘修正能力」,但代價是**過擬合風險**(只有 6 個點配 4 個係數,樣本剛好夠,擠了點)。

A 比較**保守、穩健**,B **稍精準但易讀性差**。

## 我的建議:**step8 sensitive 比較正當**

### 理由 1:**眼睛看不到的錯比看得到的錯更可疑**

step6 的低濃度漏抓**你親眼看到了**,有圖為證,**這是確認的錯誤**。


### 理由 4:**對使用者誠實**

App 預測值跟「相機看到的東西」要一致。如果用戶拍的水**看起來有很多細胞**,但 App 說「13,000 cells/mL」(用 step6 校準),用戶會懷疑 App 壞了。

## 「綠色更多」的兩種意思

### 視覺直覺(沒錯)
你看燒杯:
- 稀的 → 偏白透明,看不太到綠
- 濃的 → **深綠**(很顯眼的綠)

→ 「濃 = 綠色更明顯」✓ 沒錯

### 光學量測(我們在做的)
我們量的是 **`色比 = 燒杯 RGB / 白卡 RGB`**(光透過藻液後剩多少)。

**Beer-Lambert 定律:濃度越高 → 吸收越多 → 透射光越少 → RGB 全部下降**

實測數據(從稀到濃):

| 通道 | 稀(1 號)| 濃(10 號)| 下降 |
|------|--------:|---------:|-----:|
| R | 0.75 | 0.22 | **降 71%** |
| **G** | **0.80** | **0.46** | **只降 43%** ⚠️ |
| B | 0.71 | 0.16 | 降 78% |

R 跟 B 大幅下降(被葉綠素強吸收 ✓ 物理對),G **下降最少**(葉綠素不太吸綠光,綠光大部分還是透過去)。

### 為什麼看起來「更綠」?
因為 **R 跟 B 降得比 G 快**:
```
稀:(R=0.75, G=0.80, B=0.71) → 三通道接近,看起來偏白
濃:(R=0.22, G=0.46, B=0.16) → G 是 R 的 2 倍!→ 視覺壓倒性偏綠
```

所以你眼睛看到「更綠」,**不是 G 變大,而是 R/B 變小,讓 G 顯得突出**。

---

## 那為什麼 G 對 OD 的 R² 最高?

| | R | G | B |
|--|--|--|--|
| 動態範圍 | 0.75 → 0.22 | **0.80 → 0.46** | 0.71 → 0.16 |
| 範圍中心 | 0.48 | **0.63**(中段)| 0.43 |
| 飽和風險 | 高(濃時接近 0)| **低(都在中段)** | 高(濃時接近 0) |

**G 通道在所有濃度下都處在「線性響應區」**(中段),不會碰到極暗(R, B 在高濃度接近 0,訊號雜訊比差)或極亮(過曝)。

R 跟 B 雖然「斜率大」(對濃度敏感),但兩端容易飽和,線性度反而被拖累。

**G 是「斜率小但全程穩定」的訊號**,所以 R² 最高。

加好了。但發現一個生物上要注意的事:

## ⚠️ Chl-b 高於 Chl-a — 不太正常

| 樣本 | Chl-a | Chl-b | Chl-b/Chl-a |
|------|------:|------:|:-----------:|
| 1 號(稀)| 3.64 | 3.28 | 0.90 ← 接近 1:1 |
| 5 號(中)| 6.27 | 8.82 | **1.41** |
| 10 號(濃)| 12.54 | 17.53 | **1.40** |

典型小球藻 / 大多數綠藻的 **Chl-a/Chl-b ≈ 2-3(Chl-a 比較多)**。我們算出來反過來了。

### 兩個可能原因

**1. Lichtenthaler 公式假設「萃取後」量 OD**
你直接拍燒杯整體混濁液(沒做丙酮萃取),OD 不只有純色素吸光,還包含**細胞散射、其他色素干擾**。公式對「whole-cell suspension」會給出系統性偏差。

**2. OD647 跟 OD664 校準資料只有 N=10**(只有 0506 量),0504 那組沒測 664/647(只測 630/647)。所以 OD664 的預測模型樣本少、偏差大。

### 修法

短期:**就這樣放**,讓 UI 顯示出來,標註是估計值。
中期:**下次量光譜時,所有 4 波長都量**(N 從 10 變 20+,模型會穩很多)。
長期:**如果要嚴謹**,做一次丙酮萃取,直接套公式得到絕對值。
