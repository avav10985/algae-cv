## Step 6 目前的計算方式

### 流程(每張圖)
1. **Cellpose 偵測** → 用 fine-tuned `my_cpsam_A` 模型偵測所有細胞
2. **自動找 1mm² 計數方格** → 用亮度 + 投影找格線,挑中央那個尺寸對的方框
3. **L-shape 規則計數** → 細胞身體碰**右**或**下**邊 = 不算;碰**上 / 左** = 算

### 濃度公式([step6_chamber_inference.py:286-291](colabtest/finetune/step6_chamber_inference.py#L286-L291))

```
total_cells          = 上室所有 L-shape 計數加總 + 下室所有 L-shape 計數加總
chambers_microliter  = (n_up / 25) + (n_down / 25)         ← 每張 = 1/25 microliter
per_microliter       = total_cells / chambers_microliter
final_concentration  = per_microliter × 1000 × DILUTION_FACTOR    ← × 1000 → cells/mL
```

### 預設假設([step6_chamber_inference.py:40-48](colabtest/finetune/step6_chamber_inference.py#L40-L48))
- `IMAGES_PER_CHAMBER = 25`(每室 25 張覆蓋 1 µL)
- `VOLUME_PER_CHAMBER_ML = 1e-3`(每室 1 µL = 10⁻³ mL)
- `DILUTION_FACTOR = 1.0`(沒稀釋)
- 換算邏輯:25 張 = 1 µL → 50 張(兩室)= 2 µL → 細胞數 ÷ µL × 1000 = cells/mL

### CSV 輸出順序
```
上室每張明細 → Step 1 上室加總
下室每張明細 → Step 2 下室加總
Step 3 兩室合計 (up_sum + down_sum)
Step 4 ÷ chambers_microliter (得每微升細胞數)
Step 5 × 1000 × dilution (回推 1 mL)
⭐ 最終濃度
```

## Cellpose 訓練細節總覽

### 起點模型
- **Base**: `cpsam` (CellPose 4.x 預訓練)
- **方法**: Fine-tune,不是從零訓練 — 因為 cpsam 已經很強,只是讓它適應你拍的藻類 + 血球計數器影像

### 超參數([step3_finetune.py:50-54](colabtest/finetune/step3_finetune.py#L50-L54))

| 參數 | 值 | 為何 |
|------|-----|------|
| `N_EPOCHS` | 100 | 夠了,再多容易 overfit |
| `LEARNING_RATE` | 1e-5 | cpsam 微調建議的低 LR |
| `WEIGHT_DECAY` | 0.1 | 正則化,避免 overfit |
| `BATCH_SIZE` | 1 | T4 16GB 跑 cpsam 大模型只能塞 1 |
| GPU | Colab T4 | |
| 訓練時間 | 20–40 分鐘 | 視張數 |

訓練 API: `cellpose.train.train_seg()`,見 [step3_finetune.py:109-121](colabtest/finetune/step3_finetune.py#L109-L121)。

### 資料
- **數量**: 20–30 組 `.jpg + _seg.npy`(實例約 1500–3000 顆細胞)
- **拆分**: `SEED=42`,5 張當 test,其他 train([split_train_test.py:23-24](colabtest/finetune/split_train_test.py#L23-L24))
- **影像來源**: 血球計數器顯微鏡照(原圖 4K,訓練在 1024 寬等比縮過)
- **diameter @ 1024**: 45 像素(推論時也用這個基準等比放大)

### 標注規則(兩套並行)

從 [README.md:48-54](colabtest/finetune/README.md#L48-L54):

| 資料夾 | 規則 | 對應模型 |
|--------|------|---------|
| `labeling_A/` | 分裂雙球當 **1** 顆 | `my_cpsam_A` ← **目前 step6/7 用這個** |

step6/7 的 `MODEL_PATH = .../cellpose_train_A/models/my_cpsam_A` 確認用的是 A 規則。

### 標注流程([step1_labeling_guide.md](colabtest/finetune/step1_labeling_guide.md))

1. **Colab 自動跑**:用 [auto_label_colab.py](colabtest/finetune/auto_label_colab.py) 拿 cpsam 對所有圖做第一版 `_seg.npy`(diameter=12 用在 1024 寬縮圖,參數 `flow_threshold=0.4`,`cellprob_threshold=0.0`)

### 標注的關鍵原則(影響模型行為)

## 加了什麼

[step3_finetune.py](colabtest/finetune/step3_finetune.py#L133-L186) 多了兩個函式跟修改後的 comparison loop:

1. **`compute_iou_matrix(pred, gt)`** — 用 `np.bincount` 算所有 pred×GT pair 的 IoU 矩陣(O(n_gt × n_pred),不 loop pixels,小圖瞬間)
2. **`evaluate_pair(pred, gt, iou_thresh=0.5)`** — Greedy 配對(依 IoU 從高到低),回 `(mean_iou, accuracy, tp, fp, fn)`
   - **mean IoU** = 所有 TP 配對的平均 IoU
   - **Accuracy** = TP / (TP + FP + FN)(Jaccard-style;一般論文叫 AP@0.5 或 Panoptic Quality 的精神)

## IoU 是什麼

**IoU = Intersection over Union(交集除以聯集)**,衡量「AI 預測的細胞輪廓」跟「人工標註的細胞輪廓」**重疊得多準**。0 到 1 之間,1 = 完美重疊。

```
   GT 標註           AI 預測
    ╭─╮              ╭─╮
    │ │  vs.     →   │ │      IoU = 重疊面積 / 總面積
    ╰─╯              ╰─╯
```

不只算「數對幾顆」,還算「畫得準不準」。

## 為什麼加這麼多

def compute_iou_matrix(pred, gt):
    """逐顆 mask × mask 算 IoU,回傳 (n_gt × n_pred) 矩陣。"""
    pred_ids = np.unique(pred); pred_ids = pred_ids[pred_ids > 0]
    gt_ids   = np.unique(gt);   gt_ids   = gt_ids[gt_ids > 0]
    n_gt, n_pred = len(gt_ids), len(pred_ids)
    if n_gt == 0 or n_pred == 0:
        return np.zeros((n_gt, n_pred))

    max_pred = int(pred_ids.max())
    overlap = (gt > 0) & (pred > 0)
    enc = gt[overlap].astype(np.int64) * (max_pred + 1) + pred[overlap].astype(np.int64)
    pair_counts = np.bincount(enc)
    gt_area   = np.bincount(gt.flatten().astype(np.int64))
    pred_area = np.bincount(pred.flatten().astype(np.int64))

    iou = np.zeros((n_gt, n_pred))
    for i, g in enumerate(gt_ids):
        for j, p in enumerate(pred_ids):
            key = int(g) * (max_pred + 1) + int(p)
            inter = pair_counts[key] if key < len(pair_counts) else 0
            union = gt_area[g] + pred_area[p] - inter
            iou[i, j] = inter / union if union > 0 else 0
    return iou


def evaluate(pred, gt, thresh=IOU_THRESH):
    """Greedy 配對,IoU≥thresh 算 TP。回傳 (mean_iou, accuracy, tp, fp, fn)。"""
    iou_mat = compute_iou_matrix(pred, gt)
    n_gt, n_pred = iou_mat.shape
    if n_gt == 0:
        return 0.0, 0.0, 0, n_pred, 0
    if n_pred == 0:
        return 0.0, 0.0, 0, 0, n_gt

    pairs = sorted(
        [(i, j, iou_mat[i, j]) for i in range(n_gt) for j in range(n_pred)],
        key=lambda x: -x[2])
    used_g, used_p, matched = set(), set(), []
    for i, j, v in pairs:
        if v < thresh: break
        if i in used_g or j in used_p: continue
        used_g.add(i); used_p.add(j); matched.append(v)

    tp = len(matched); fp = n_pred - tp; fn = n_gt - tp
    mean_iou = float(np.mean(matched)) if matched else 0.0
    accuracy = tp / (tp + fp + fn) if (tp + fp + fn) > 0 else 0.0
    return mean_iou, accuracy, tp, fp, fn

## 三個指標白話解釋

### 1️⃣ Mean IoU(平均交集比聯集)

衡量「**畫得準不準**」— AI 抓到的細胞輪廓 vs 人工標註的輪廓,**重疊面積佔總面積的比例**。

```
GT 標註輪廓     AI 預測輪廓        重疊區
   ◯              ◯           IoU = 重疊 / 聯集
                                    = 0 → 完全沒對到
                                    = 1 → 完美貼合
                                    > 0.5 → 算「成功識別」(行業標準)
```

你的數字:0.892 → 平均**重疊度 ~89%**,單顆細胞畫得很準。

---

### 2️⃣ Accuracy(準確率,Jaccard 風)

衡量「**有沒有抓對該抓的、沒亂抓多的**」— 公式:

```
Accuracy = TP / (TP + FP + FN)

TP = True Positive   = 對的細胞被抓到了(IoU≥0.5 算過關)
FP = False Positive  = 抓到「不是細胞的東西」(雜質、格線殘影)
FN = False Negative  = 沒抓到「真實存在的細胞」(漏抓)
```

舉例:GT 有 60 顆,AI 抓 70 顆,其中 55 顆有對到 → TP=55, FP=15(多抓), FN=5(漏抓)
→ Accuracy = 55 / (55+15+5) = **73.3%**

你的數字:fine-tuned **0.921** → 92% 的細胞被「正確識別」(數對且畫對)。

cpsam **0.235** → 雖然有對到的部分畫得準(IoU 0.871),但**抓太多假東西**(105 顆 vs 真實 55 顆,FP 太多),所以 Accuracy 慘。

---

### 3️⃣ Count MAE(平均絕對誤差,Mean Absolute Error)

衡量「**最簡單的數細胞數對不對**」— 公式:

```
MAE = average( |AI預測數 − 人工真實數| )
```

每張圖算一次差,取平均。

你的數字:
- cpsam MAE = 46.20 → 平均**每張差 46 顆**(預測 105、真實 55,差 50)
- fine-tuned MAE = 1.00 → 平均**每張只差 1 顆**
